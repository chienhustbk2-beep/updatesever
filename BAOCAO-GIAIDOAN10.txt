--- api/admin/orders/[id]/route.ts ---
  Vị trí: C:\Users\Chien Hust\ecommerce-digital\src\app\api\admin\orders\[id]\route.ts
  Method: PATCH
  Chức năng: Cập nhật trạng thái đơn hàng
  Body nhận: { status?, paymentStatus?, note? }
  Bảo mật: Kiểm tra đăng nhập + role ADMIN
  Validation:
    - Chỉ chấp nhận status hợp lệ: PENDING, PROCESSING, COMPLETED, CANCELLED, REFUNDED
    - Chỉ chấp nhận paymentStatus hợp lệ: UNPAID, PAID, FAILED, REFUNDED
    - Tự động set paymentStatus = PAID khi status = COMPLETED

4. CẬP NHẬT TRẠNG THÁI ĐƠN HÀNG
================================================================================

  API: PATCH /api/admin/orders/[id]
  Headers: Content-Type: application/json
  Cookie:_next-auth.session-token (yêu cầu đăng nhập ADMIN)

  Body ví dụ:
  {
    "status": "COMPLETED"
  }

  Response thành công:
  {
    "success": true,
    "message": "Cập nhật đơn hàng thành công",
    "order": { ... }
  }

  UI: Tại trang /admin/orders, mỗi dòng có:
    - Dropdown chọn trạng thái
    - Nút "Cập nhật"
    - Thông báo kết quả (xanh = thành công, đỏ = lỗi)
