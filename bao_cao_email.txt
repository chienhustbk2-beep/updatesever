BAO CAO TICH HOP HE THONG EMAIL TU DONG (NODEMAILER)
====================================================

1. MUC DICH
   - Gui email thong bao cho nguoi dung khi nap tien thanh cong
   - Admin co the cau hinh SMTP truc tiep trong giao dien Admin
   - Ho tro ca SePay (VietQR) va Web2M

2. CAC FILE DA TAO MOI
   - src/lib/mail.ts: Module gui email core (nodemailer)
     * sendMail(): Lay cau hinh SMTP tu DB, tao transporter va gui mail
     * depositSuccessTemplate(): Tao HTML template thong bao nap tien thanh cong
     * Tu dong bo qua neu SMTP chua duoc cau hinh (khong crash)

3. CAC FILE DA SUA
   - src/app/api/webhook/sepay/route.ts:
     * Them import sendMail, depositSuccessTemplate
     * Them block gui email sau khi xu ly giao dich moi (alreadyProcessed === false)
     * Gui den email cua user (user.email)

   - src/app/api/web2m/sync/route.ts:
     * Them import sendMail, depositSuccessTemplate
     * Them block gui email sau khi xu ly giao dich moi (result.status === "processed")
     * Lay lai balance sau khi cong tien de hien thi so du chinh xac

4. CAU HINH ADMIN (DA CO SAN)
   - Tab "Cau hinh Email (SMTP)" trong Admin Settings:
     * SMTP Host (vd: smtp.gmail.com)
     * SMTP Port (vd: 587)
     * SMTP User (email gui)
     * SMTP Password (mat khau ung dung)
     * From Email (dia chi nguoi gui hien thi)

5. PACKAGE DA CAI DAT
   - nodemailer: ^6.x
   - @types/nodemailer: ^6.x

6. LUU Y
   - Gmail yeu cau "Mat khau ung dung" (App Password) thay vi mat khau thuong
     (Can bat xac thuc 2 buoc -> Quan ly tai khoan -> Mat khau ung dung)
   - SMTP config duoc lay tu DB (SystemSettings) => Admin co the thay doi bat ky luc nao
   - Neu SMTP chua cau hinh, ham sendMail() tu dong bo qua (log warning)
   - HTML template hien thi: ten nguoi dung, so tien nap, ma giao dich, so du moi

7. BIEN MOI TRUONG
   - Khong can them bien moi truong moi (SMTP config lay tu DB qua Admin UI)
